Agentic Lending Policy RAG — RBI & Bank Policy Assistant

GenAI · Agents

Answers credit and lending questions from 11 RBI Directions and 7 bank policies (829 pages) with a page-level citation on every claim, and says so when the documents do not cover a question. Compares plain RAG with a hand-written ReAct agent and a LangGraph agent over hybrid BM25 + dense search and a cross-encoder re-ranker, with calculator tools for EMI and LTV. On a 60-question gold set checked by hand against the PDFs, the agents reach 90–91% correct against 82% for plain RAG; fixes were judged on separate holdout questions. Guardrails, 119 offline tests in GitHub Actions, and a live demo, all on free tiers.
